# 明日方舟 1-7 后台脚本

这个脚本使用 MuMu 自带 ADB 操作名为 `明日方舟` 的模拟器实例，不依赖鼠标前台点击。

## 常用命令

## 双击入口

从 MuMu 的 `明日方舟` 设备桌面开始：

```text
从设备桌面启动并刷1-7.exe
```

已经进入《明日方舟》游戏主界面时：

```text
游戏内找1-7刷图.exe
```

旧入口仍然保留，等同于全自动从设备桌面/游戏内继续：

```text
启动1-7刷图.exe
```

只找到 1-7，不开始刷：

```powershell
.\run_ark_1_7.ps1 --mode find
```

找到 1-7 后循环刷图：

```powershell
.\run_ark_1_7.ps1 --mode find-and-loop
```

如果 MuMu 的 `明日方舟` 设备已经打开，但还停在安卓桌面，直接运行同一个命令即可。脚本会先启动游戏，点过标题页/登录页，等进入主界面后再自动找 1-7。

当前已经在 1-7 页面时直接循环：

```powershell
.\run_ark_1_7.ps1 --mode loop
```

最多刷 3 次：

```powershell
.\run_ark_1_7.ps1 --mode loop --max-runs 3
```

隐藏 MuMu 窗口后后台跑：

```powershell
.\run_ark_1_7.ps1 --mode find-and-loop --hide-window
```

## 规则

- 如果游戏不在前台，脚本会先启动 `com.hypergryph.arknights`。
- 如果停在 START / 开始唤醒页面，脚本会自动点击并等待进入主界面。
- 如果首次登录遇到每日签到、每日公告或类似弹窗，脚本会先尝试关闭/点掉，再继续等待主界面。
- 找 1-7 走你截图里的固定路径：主界面终端 -> 主线/曲谱 -> EP01 Part 2 -> 前往章节 -> 1-7。
- 在 1-7 页面点 `开始行动`。
- 进入编队确认页后，点右侧橙色 `开始行动`。
- 等到左侧出现 `行动结束 / MISSION RESULTS` 结算页后，点击画面回到 1-7 页面。
- 如果理智不足弹出恢复窗口，只在当前选中的药剂时间标签看起来是红/粉色 `<=2天` 时确认使用。
- 如果当前选中的是绿色 `9天` 这类长时间药剂，就点叉关闭并停止。

脚本会把关键截图保存在 `ark_1_7_debug`，如果识别失败可以看这个目录里的截图校准坐标。
